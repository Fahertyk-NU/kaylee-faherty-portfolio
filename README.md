## Project Objective

A personal and professional portfolio homepage for Kaylee Faherty, a data science graduate student at Northeastern University's Roux Institute and former chemical engineer. The site is designed to give visitors a complete picture of who Kaylee is, from her technical skills and academic projects to her personality and life outside of work.

## Tech Requirements

- Google Fonts (Playfair Display, Lato)
- ESLint + eslint-config-prettier
- Prettier

---

## Instructions to Build

```bash
# Clone the repository
git clone https://github.com/Fahertyk-NU/kaylee-faherty-portfolio.git

# Navigate into the project
cd kaylee-faherty-portfolio

# Install dev dependencies
npm install

# Lint JS files
npm run lint

# Format all files with Prettier
npm run format
```

Open `index.html` in a browser or visit the live site linked above.

## GenAI Usage

**Model:** Claude Sonnet (Anthropic) — claude-sonnet-4-6

**How it was used:**

Claude was used throughout this project as a sounding board and learning tool rather than writing code directly, with the exception of the Get to Know Me page. It was used to help with the design document process, HTML structure, Bootstrap layout, CSS styling, and content writing. The Get to Know Me page HTML, CSS, and JS files were entirely generated by Claude using the prompt below and then revised by me.

**Prompt used to generate the Get to Know Me page:**

_"Please generate a 'Get to Know Me' personal Q&A page for my portfolio website. The page should include a navbar, 6 Q&A items with placeholder questions and answers, and a footer. Use Bootstrap 5.3.2, Google Fonts (Playfair Display for headings, Lato for body), accent color #8FAF8F, and background color #FAF9F7. Keep the design clean and minimal."_

**Prompt used to generate the ReadMe framework:**
_"Please write a README.md for my personal portfolio website project. Include the following sections: project name, Author, a link to the live site, Class Link, Project Objective, Screenshot, Tech Requirements, Instructions to Build, GenAI Usage, link to Video Demonstration, and License. The project is a personal portfolio homepage built with vanilla HTML5, CSS3, and ES6+, Bootstrap 5, ESLint and Prettier. Use GitHub Markdown formatting."_

All other HTML, CSS, and JavaScript was written by Kaylee Faherty.
